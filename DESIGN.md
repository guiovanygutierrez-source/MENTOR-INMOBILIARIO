# Academia nocturna inmobiliaria

## Direction

Mentor Inmobiliario Colombia is an educational studio for people learning to make housing decisions in Colombia. The interface is a precise, modern night academy: deep navy spaces, slate work surfaces, ice-blue text, and vivid cyan for interactive choices and progress. Keep the learning path familiar and comfortable for first-time buyers while giving the app a technical, immersive visual identity.

The visual language pairs architectural learning diagrams with a modular Three.js scene on the dashboard. Abstract building volumes, fine cyan edges, moving light, and restrained orbital geometry signal spatial thinking without implying property listings. Keep a static vector plan fallback so all learning content remains available if WebGL or the Three.js CDN is unavailable. Plans and sample figures must be labeled as educational illustrations, never as listings or financial promises.

## Color strategy

Committed dark shell. Navy owns the application ground and navigation; slate owns cards, forms, and reading surfaces; ice-blue carries primary text; cyan marks navigation, selections, actions, diagrams, and progress. Reserve warm amber and coral for meaningful warning, pending, or error states. Check every palette combination for text contrast.

## Typography and materials

Use a clean display face with a highly legible sans-serif for learning text and controls. Keep fonts bundled locally so the interface does not depend on a remote font request. Keep paragraphs at a comfortable reading measure and make lesson headings visibly stronger than their supporting labels.

Use clear vector geometry, measured rules, subtle technical texture, depth lighting, and restrained motion. Do not cover content in blueprint grids. Avoid generic card grids, excessive rounded pills, decorative gradients, emoji icons, and progress rings.

## Interaction grammar

- Keep ordinary web navigation, buttons, inputs, tabs, dialogs, and forms familiar.
- Make learning hands-on: a small choice, check, or editable case should follow an explanation.
- Show a visible next step and let the learner reach the optional Mentor from every important learning surface.
- Use purposeful geometric interactions: the plan diagram links to learning and the dashboard's 3D model responds gently to pointer movement.
- Keep motion brief, interruptible, and useful; respect reduced motion, pause WebGL offscreen, and preserve a static rendering fallback.

## Product truth

Preserve the 10-module route, lesson content, video resources, quizzes, simulators, glossary, saved work, authentication, and Mentor. Mentor remains an optional AI assistant for user questions, with the current local fallback and Gemini controls intact. The visual refresh cannot imply web research, approvals, listings, investment returns, or financial guarantees where the product does not provide them.

## Responsive behavior

Desktop uses a compact persistent navigation rail and a clear work area. Tablet and mobile keep the same information order and expose navigation through the existing accessible menu. Plan diagrams must remain readable, operable, and labeled at narrow widths. Inputs remain touch-friendly and no fixed assistant control may cover lesson content.
